# 🚨 Быстрое исправление проблем с миграцией

## ❌ **Проблемы:**
1. **Ошибка с полем `name` в таблице `club`** - поле называется `title`
2. **PHP скрипты не запускаются** - ошибка загрузки Laravel
3. **Команда `php artisan db:adapt` падает** - неправильная структура

## ✅ **Быстрое решение:**

### **Шаг 1: Исправление структуры БД**

Запустите простой скрипт:

```bash
php fix_database_structure.php
```

**Что он делает:**
- ✅ Добавляет недостающие поля в существующие таблицы
- ✅ Создает отсутствующие таблицы (`specialists`, `likes`, `dislikes`)
- ✅ Не ломает существующие данные
- ✅ Показывает подробный отчет

**Пример вывода:**
```

✅ Подключение к БД установлено
📊 Обрабатываем таблицу users...
  ➕ Добавлено поле slug
  ➕ Добавлено поле avatar
📝 Обрабатываем таблицу blogs...
  ➕ Добавлено поле tags
🏛️ Обрабатываем таблицу club...
  ➕ Добавлено поле short_description
👨‍⚕️ Создаем таблицу specialists...
  ✅ Таблица specialists создана

🎉 Исправления завершены!
📊 Всего изменений: 8
✅ Теперь можете запустить: php artisan db:adapt
```

### **Шаг 2: Проверка через веб-интерфейс**

Если нужна детальная проверка, используйте:

```
https://ваш-сайт.com/check_db_structure.php
```

**Настройте подключение к БД в начале файла:**
```php
$host = 'localhost';
$dbname = 'apspy_beta'; // Ваше имя БД
$username = 'root';
$password = 'ваш_пароль';
```

### **Шаг 3: Запуск команд Laravel**

После исправления структуры:

```bash
# Адаптация БД
php artisan db:adapt

# Миграция данных
php artisan data:migrate --type=all

# Миграция аватаров
php artisan avatars:migrate
```
